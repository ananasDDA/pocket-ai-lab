What is Pocket AI Lab?

Pocket AI Lab is a free iPhone app that downloads open LLMs from Hugging Face and runs them on the phone's own chip, so chats work without internet and never leave the device.

It's built like a small lab bench. You see which runtime is generating, how fast, how hot the phone is getting and how much memory the model really uses. The same model can be run on different backends and measured with the built-in benchmark, which grades it on 46 tasks and produces a report card you can share.

Who is it for?

It's for people who want a private assistant that works offline, and for developers who want to know how a model actually behaves on an iPhone before they build on it.

✈️ offline

Private, offline chat

On a plane, in the metro, or just when you'd rather not paste things into a cloud chatbot. After the download, the model runs with no network at all.

🧪 evaluate

Picking an on-device model

Compare GGUF against MLX, check tokens per second, load time and peak memory on your own phone, and export the report as JSON.

🤗 tinker

Trying new models

Paste a Hugging Face link, pick a quantization and get a fits / doesn't fit verdict for your device before a single byte downloads.

How does it work?

The app scans the phone, filters the catalog against the memory iOS really allows, downloads the model from Hugging Face and streams the answer token by token from whichever backend fits the model.

  1. Scan

    Chip, RAM, free disk, the per-app memory allowance from os_proc_available_memory and the Metal working-set limit.

  2. Recommend

    MLX and Core ML models are judged against the strict app limit. Memory-mapped llama.cpp and whisper.cpp models against the higher GPU working set.

  3. Download

    Background download pinned to an exact repo revision. It survives app restarts, and the catalog itself updates from GitHub.

  4. Chat

    Every backend speaks one streaming interface, with full conversation history and live CPU, RAM and thermal readings.

Which inference backends does it support?

Five: llama.cpp for GGUF files, MLX Swift for MLX weights and vision models, Core ML, Apple's built-in Foundation Models, and whisper.cpp for speech-to-text.

GGUF

llama.cpp

Runs GGUF files, the most common format for quantized models on Hugging Face. Weights are memory-mapped, so a 3B model at Q4_K_M peaked at 696 MB in our sweep. Vision models work through a separate mmproj projector.

safetensors

MLX Swift

Apple's array framework for Apple silicon. Runs the 4-bit models from mlx-community, plus vision-language models that take photos and video frames.

.mlmodelc

Core ML

Compiled Core ML packages, loaded through swift-transformers. On the current catalog model prompt reading is fast (about 703 tok/s) and generation slow (3.4 tok/s).

system

Apple Foundation Models

The ~3B model that ships with Apple Intelligence. Nothing to download. Needs an Apple Intelligence iPhone with the feature turned on.

ggml

whisper.cpp

Speech-to-text. Record a voice message and the Whisper model turns it into text on the phone. 80 MB for tiny.en.

+ your own

Import by link

Paste owner/repo from Hugging Face. GGUF, MLX safetensors, Core ML and Whisper files are detected, Q4_K_M is preselected.

How fast do LLMs run on an iPhone?

On an iPhone Air with the A19 chip, 2B to 4B models generated 21.5 to 37.9 tokens per second in Pocket AI Lab 1.0.1. That's faster than most people read.

Can I run any model from Hugging Face?

Mostly yes. Paste a public repo link and the app reads the file list, offers the available quantizations and shows a RAM and disk verdict for your phone before downloading.

GGUF files from the Files app work too. Gated repos (the ones where you accept a license on the website first) can't be downloaded, because the app downloads anonymously and never asks for your Hugging Face token. A mirror repo of the same model usually works.

What do I need to run it?

An iPhone on iOS 26.1 or later, and for local models at least 6 GB of RAM, which means iPhone 15 or newer.

  • Apple Foundation Models also need Apple Intelligence turned on, so iPhone 15 Pro or newer.
  • Storage depends on the model, from 80 MB for Whisper tiny to 8.5 GB for Qwen 2.5 14B. The app itself is 40.5 MB.
  • The app is universal, so it installs on iPads with iPadOS 26.1 too. Published benchmarks so far come from an iPhone.

Is Pocket AI Lab open source?

Yes. The full Swift source is on GitHub under the MIT license, and the model catalog the app downloads lives in the same repository.
