How does the app decide what fits my iPhone?

It compares each model's memory need with two limits it reads from your phone at launch: the per-app allowance iOS grants before it kills the app, and the GPU working set.

The phone's RAM figure isn't what an app gets. iOS kills a process that crosses its memory limit (jetsam), and that limit sits well below physical RAM. Pocket AI Lab requests Apple's increased-memory-limit entitlement and then measures the real allowance with os_proc_available_memory.

MLX and Core ML copy weights into memory, so they're checked against that allowance. llama.cpp and whisper.cpp map the file instead, so they're checked against the larger Metal working set. The model offered as recommended has to stay under 85% of its budget, because a model that barely fits loads and then dies once the context grows.

Can I add a model that isn't in the catalog?

Yes. In the Models tab tap ⊕ and paste a Hugging Face repo, or pick a GGUF file from the Files app.

The catalog itself is a JSON file in the GitHub repository. The app refreshes it on launch, so new curated models show up without an App Store update.

Pocket AI Lab

Pocket AI Lab is an offline LLM app for iPhone. It runs open models from Hugging Face on the device, with no account and no server. Free on the App Store, source code under the MIT license.

Not affiliated with Hugging Face, Apple, Meta, Google, Microsoft, Mistral AI or Alibaba. Model names belong to their owners, and each model keeps its own license.
